# Riverland · Dream Matcha Rotation

Experiencia interactiva para montar una mesa virtual con artistas de Riverland. Puedes filtrar el cartel por día, generar una selección aleatoria y copiar tu lineup.

[Visitar la web](https://dnsue01.github.io/RiverlandMatcha/)

## En el repositorio

`artists.js` contiene el catálogo de artistas, `app.js` controla la interacción y `styles.css` define la presentación.
